## Findings (RAN)

C7 (`decrypted_shares_aggregation.nr`): pure deterministic arithmetic — d-commitment (T+1 sha-
assert), Lagrange, CRT, decode mod `t` (BigNum + ModU64). NO sponge, NO challenge, NO payload()
(grep 0 hits source+bin). Source-minimal by construction, same class as the C2 leaves r111 and
the 4 seam folds r112. No C7 lever.

C6 (`share_decryption.nr:186-202`): `payload()` pushed raw `ct0`+`ct1` limbs (2 L polynomials ×
N=8192 coeff × BIT_CT=57 = 16,386 packed carriers at secure-8192/L=3, per the `pack` layout in
`math/helpers.nr:30-134` — nibble_bits=60, group=3, radix=2^64) into the Fiat-Shamir sponge.
The SAME limbs are already (a) bound to the PUBLIC `ct_commitment` by `verify_ct_commitment`
(line 161, `compute_ciphertext_commitment::<N,L,BIT_CT>(ct0,ct1) == ct_commitment`) and (b) related
at the FS-derived `gamma` by `verify_decryption_share_computation` (line 311). Both bind the exact
same packed-payload that the I14 lever shaves, verbatim the C3 shipped pattern
(`dkg/share_encryption.nr:236-246` — line 246 `inputs = inputs.push_back(ct_commitment)`, with
the same in-circuit commitment-assert + Zeus guard as C6 here).

## Delivery

Patch (3 small edits in `share_decryption.nr`, +15/−8; hex-restricted, ASCII/UTF-8 only, no
typed-literal redaction risk):
  line 186   `fn payload(self) -> [Field]`
             → `fn payload(self, ct_commitment: Field) -> [Field]`
             drop `flatten::<_,_,BIT_CT>(inputs, self.ct0); flatten::<_,_,BIT_CT>(inputs, self.ct1);`
             (the 16,386-carrier line pair), add `inputs = inputs.push_back(ct_commitment);`
             with a KEY comment binding to the precedent shipped into C3
  line 283   `fn generate_challenge(self)`  → `fn generate_challenge(self, ct_commitment: Field)`
             `let inputs = self.payload();`  → `let inputs = self.payload(ct_commitment);`
  line 225   `let gamma = self.generate_challenge();`
             → `let gamma = self.generate_challenge(self.ct_commitment);`
             (public input already verified equal to the limb-derived commitment in step 3)
