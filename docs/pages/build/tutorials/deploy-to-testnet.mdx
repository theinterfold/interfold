# Deploy Your E3 to Sepolia

This tutorial takes you from a working local E3 (from [Quick Start](/quick-start) or CRISP) to a
live deployment on Sepolia testnet.

> **What you'll build:** Your E3 program contract deployed to Sepolia, a coordination server pointed
> at a Sepolia RPC, and a verified end-to-end E3 round against the live testnet ciphernode
> committee.
>
> **Prerequisites:** A working local E3, Sepolia ETH for gas, a WebSocket RPC endpoint (e.g.
> Alchemy, Infura), and your deployer private key funded.

---

## 1. Get Testnet Tokens

You'll need:

- **Sepolia ETH** — for gas. Any public Sepolia faucet works, e.g.
  [sepoliafaucet.com](https://sepoliafaucet.com),
  [Google Cloud faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia), or
  [PoW faucet](https://sepolia-faucet.pk910.de).
- **Test FOLD** — for ciphernode bonding (only if you're running your own nodes). The InterfoldToken
  (FOLD) is deployed at `0x9752444A6a955D420402EaFf5f818afCddb9c340`.
- **Test USDC** — for E3 fees and tickets. Mock USDC at
  `0xC35B783cA97710be47Fc81D10dADc895EfcD865c`.

> **Faucet:** the quickest way to get both test tokens is the on-chain faucet at
> `0x6e281411C055BEEbD74bDFcB9aB095aa98907F85`. Run `interfold faucet` (with the `faucet` address
> set in your config) and it sends a fixed amount of FOLD and mock USDC to your signer. Each token
> is only topped up if your balance is below the per-token threshold. If the faucet runs dry, reach
> out on the [community Telegram](https://t.me/enclave_e3).

> The full list of deployed Sepolia addresses lives in

> [Ciphernode Operators → Sepolia Contract Addresses](/ciphernode-operators#sepolia-contract-addresses)
> and in `packages/interfold-contracts/deployed_contracts.json` inside the repo.

## 2. Configure Environment

Create or update your `.env` file with Sepolia settings:

```bash
# Sepolia RPC (WebSocket required for event listening)
WS_RPC_URL=wss://eth-sepolia.g.alchemy.com/v2/YOUR_KEY
HTTP_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/YOUR_KEY

# Deployer private key (has Sepolia ETH)
PRIVATE_KEY=0x...

# Chain
CHAIN_ID=11155111

# Deployed Interfold contract addresses (Sepolia)
INTERFOLD_ADDRESS=0x3E856E24c7a95d0e04d387f847DA6FA9f6F6c20C
CIPHERNODE_REGISTRY_ADDRESS=0x374F4542eC634d5437Dd65020781A9D9Df9c2AB8
FEE_TOKEN_ADDRESS=0xC35B783cA97710be47Fc81D10dADc895EfcD865c
```

## 3. Deploy Your E3 Program Contract

If you're deploying your own E3 program contract (not using an already-deployed one):

```bash
# From your project root
pnpm deploy:contracts --network sepolia
```

This uses Hardhat to deploy your contracts to Sepolia. Make sure `hardhat.config.ts` has the Sepolia
network configured:

```typescript
// hardhat.config.ts
networks: {
  sepolia: {
    url: process.env.HTTP_RPC_URL,
    accounts: [process.env.PRIVATE_KEY],
  },
}
```

Note the deployed contract address — you'll need it for the E3 request and the server config.

### Verify on Etherscan

Publishing source makes your contract inspectable and lets users interact with it from Etherscan's
UI. Set an Etherscan API key and run:

```bash
# .env
ETHERSCAN_API_KEY=your_key

# Verify
pnpm hardhat verify --network sepolia <YOUR_PROGRAM_ADDRESS> <constructor-arg-1> <constructor-arg-2>
```

Constructor args are whatever you passed to your program's constructor — typically the Interfold
contract address and any verifier addresses.

### Save the address

Persist the deployed address in `.env` so your server and frontend pick it up automatically:

```bash
# Append the fresh address — don't forget this step
echo "E3_PROGRAM_ADDRESS=<deployed_address>" >> .env
```

## 4. Keep the Insecure BFV Preset on Sepolia

Sepolia runs the insecure preset. Keep `INSECURE_THRESHOLD_512` in your SDK initialisation, and
request E3s with `paramSet: 0`:

```typescript
const sdk = new InterfoldSDK({
  // ... other config
  thresholdBfvParamsPresetName: 'INSECURE_THRESHOLD_512',
})
```

```typescript
const requestParams = {
  committeeSize: CommitteeSize.Minimum,
  inputWindow: [startTime, endTime] as const,
  e3Program: YOUR_PROGRAM_ADDRESS,
  computeProviderParams: '0x...',
  paramSet: 0, // ParamSet.Insecure512
}
const quote = await sdk.getE3Quote(requestParams)
const approvalHash = await sdk.approveFeeToken(quote)
await sdk.waitForTransaction(approvalHash)
const hash = await sdk.requestE3({ ...requestParams, maxFee: quote })
```

The SDK preset and the `paramSet` in the request must agree, and both must match what the ciphernode
network runs. Sepolia is a functional testnet: it exercises the full E3 lifecycle, but it gives no
cryptographic security, so do not put real secrets in it.

`SECURE_THRESHOLD_8192` (`paramSet: 1`) is the production preset. It uses a larger polynomial ring
(N=8192 instead of N=512), so proof generation is much slower, and it needs `secure-8192` circuit
artifacts that do not ship in `@interfold/sdk` — see
[Proving: embedded circuits or your own](../sdk#proving-embedded-circuits-or-your-own).

## 5. Configure the Server

Update your coordination server to point to Sepolia:

```bash
# .env for the server
WS_RPC_URL=wss://eth-sepolia.g.alchemy.com/v2/YOUR_KEY
HTTP_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/YOUR_KEY
INTERFOLD_ADDRESS=0x3E856E24c7a95d0e04d387f847DA6FA9f6F6c20C
E3_PROGRAM_ADDRESS=<your deployed program address>
CHAIN_ID=11155111
```

Start the server:

```bash
pnpm dev:server
```

The server will connect to Sepolia via WebSocket and begin listening for E3 events.

## 6. Test End-to-End

1. **Request an E3** — via the SDK or your frontend
2. **Wait for committee formation** — the Sepolia ciphernode committee will perform sortition and
   DKG (this takes longer than local dev due to real block times)
3. **Submit encrypted inputs** — your frontend encrypts under the threshold public key and submits
4. **Wait for computation** — the compute provider runs the FHE program
5. **Check the result** — the committee decrypts and publishes the plaintext

Monitor progress by watching for events:

```typescript
sdk.onInterfoldEvent(InterfoldEventType.E3_REQUESTED, (e) => console.log('E3 requested'))
sdk.onInterfoldEvent(RegistryEventType.COMMITTEE_PUBLISHED, (e) => console.log('Committee ready'))
sdk.onInterfoldEvent(InterfoldEventType.CIPHERTEXT_OUTPUT_PUBLISHED, (e) =>
  console.log('Output ready'),
)
sdk.onInterfoldEvent(InterfoldEventType.PLAINTEXT_OUTPUT_PUBLISHED, (e) =>
  console.log('Result:', e.data),
)
```

## Troubleshooting

| Issue                       | Possible cause                           | Fix                                                                          |
| --------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------- |
| E3 request reverts          | Insufficient fee token approval          | Call `sdk.approveFeeToken()` first                                           |
| Committee never forms       | Not enough active ciphernodes on Sepolia | Check the registry for active operators                                      |
| Proof generation fails      | Preset mismatch with the SDK's circuits  | The embedded circuits are `insecure-512`; compile your own for other presets |
| Decryption produces garbage | BFV preset mismatch                      | Verify both SDK and E3 request use `INSECURE_THRESHOLD_512` / `paramSet: 0`  |
