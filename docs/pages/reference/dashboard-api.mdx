# Status Page JSON

A node serves its status as JSON when the configuration sets `dashboard_port`. Use it to connect a
monitoring system or a script. To turn on the page, see [Node Dashboard](/operate/dashboard).

```text
GET http://127.0.0.1:<dashboard_port>/status.json
```

The server binds only to `127.0.0.1`, has no authentication, and answers only `GET`. It changes
nothing in the node. The values are at most five seconds old.

| Field      | Type    | Meaning                                                                          |
| ---------- | ------- | -------------------------------------------------------------------------------- |
| `operator` | String  | The operator address.                                                            |
| `chain_id` | Number  | The chain the node reads.                                                        |
| `head`     | Number  | The newest block the chain node reported.                                        |
| `read_to`  | Number  | The last block the node has read.                                                |
| `peers`    | Number  | The peers connected now.                                                         |
| `active`   | Boolean | Whether the operator is active, from the logs the node has read.                 |
| `enabled`  | Boolean | Whether the ciphernode registry lists the operator.                              |
| `e3s`      | Array   | Each E3 the node holds: `id`, `stage`, and `owes`, a list of what it still owes. |
| `notes`    | Array   | The newest 50 notes: `sequence`, `at` (Unix seconds), and `note`.                |

A node that reads no new blocks shows `read_to` that stops moving while `head` moves. A node with no
connections shows `peers` as 0.

To read every note from a cursor, use `interfold node events --since <sequence>`.
