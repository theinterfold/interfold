# Installation

This guide covers how to install the Interfold CLI and get your development environment set up.

## Prerequisites

Before installing Interfold, make sure you have the following dependency installed:

- [Rust](https://www.rust-lang.org/tools/install)

For full hardware and software requirements, see [System Requirements](/requirements).

## Quick Install (Recommended)

The easiest way to install the Interfold CLI is using our installer script:

```bash
curl -fsSL https://raw.githubusercontent.com/theinterfold/interfold/main/install | bash
```

Or if you prefer `wget`:

```bash
wget -qO- https://raw.githubusercontent.com/theinterfold/interfold/main/install | bash
```

This script will download and install `interfoldup`, which is the standalone installer for the
Interfold CLI.

## Using interfoldup

Once you have `interfoldup` installed, you can manage your Interfold CLI installation:

### Install the Interfold CLI

```bash
# Install to ~/.local/bin (default)
interfoldup install

# Install to /usr/local/bin (requires sudo)
interfoldup install --system

# Install a specific release
interfoldup install --version v0.13.0
```

Running `interfoldup install` will install the latest version of the Interfold CLI. Give
`--version` a release tag to install that release instead. See `interfoldup --help` for more
options.

### Update the Interfold CLI

```bash
# Update to the latest version
interfoldup update

# Update system-wide installation
interfoldup update --system

# Move to a specific release, forward or backward
interfoldup update --version v0.13.0
```

### Uninstall

```bash
# Remove the Interfold CLI
interfoldup uninstall

# Remove system-wide installation
interfoldup uninstall --system
```

## Manual Installation

If you prefer to install manually:

1. Visit the [releases page](https://github.com/theinterfold/interfold/releases)
2. Download the appropriate release archive for your platform:
   - Linux: `interfold-linux-x86_64.tar.gz`
   - macOS: `interfold-macos-aarch64.tar.gz`
3. Extract the binary and place it in your PATH (e.g., `~/.local/bin` or `/usr/local/bin`)
4. Make sure the binary is executable: `chmod +x interfold`

## Platform Support

| Platform | Architecture             | Status           |
| -------- | ------------------------ | ---------------- |
| Linux    | x86_64                   | ✅ Native binary |
| macOS    | Apple Silicon (M1/M2/M3) | ✅ Native binary |
| macOS    | Intel                    | ✅ Via Rosetta 2 |

_Note: Intel Macs automatically run Apple Silicon binaries through Rosetta 2 translation._

### Building from Source

If you need to build `interfold` from source:

1. Ensure you have Rust installed (using [rustup](https://rustup.rs/))
2. Clone the repository

```bash
git clone https://github.com/theinterfold/interfold.git
cd interfold
```

3. Build the binary

```bash
cargo install --locked --path ./crates/cli --bin interfold -f
```

## Verify Installation

After installation, verify that the Interfold CLI is working correctly:

```bash
interfold --help
```

You should see the help information for the Interfold CLI.
