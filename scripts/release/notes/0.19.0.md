v0.19.0 is a governance cutover from v0.18.0. Requests stay paused until governance has upgraded the
contracts and enough operators run this release.

- Run v0.19.0 only after the cutover batch has executed. The release requires protocol version 8 and
  node generation 2, which a v0.18.0 node does not meet.
- The storage schema changes from 7 to 8. Stop each node when it serves no active E3, back up its
  data, and reset its state with the new binary before the first start
  ([Reset node state](https://docs.theinterfold.com/operate/upgrades#reset-node-state)). The reset
  keeps the operator key and the libp2p key.
- A Docker node that started from an earlier image without a volume at the configuration path keeps
  its state inside the container. Move it onto the volume before you remove the container
  ([Move state from an earlier image](https://docs.theinterfold.com/operate/running#move-state-from-an-earlier-image)).
- Setup commands take the password and the private key only from standard input or a prompt, no
  longer from command-line flags.
- The first start acknowledges the release on chain and refreshes the operator.
