v0.19.1 is a rolling patch upgrade from v0.19.0. It contains node fixes only and none of the later
`main` work.

- Replace the binary or image and restart. Do not reset node state: the storage schema, the gossip
  and sync wire versions, the protocol version and the node generation do not change, so v0.19.0 and
  v0.19.1 nodes run side by side.
- The circuits are the same as in v0.19.0. The node downloads the archive of this release.
- The first start acknowledges the new release on chain, as every release does. The operator key
  needs enough gas for one transaction.
- A chain reader that cannot recover now stops the node with an error. Run the node under a
  supervisor that restarts it, such as Docker `restart:` or systemd.
